## Observed validation

The release operator verified npm publication and installation from the registry. Installation passed on Node.js 20 in ruOS and Node.js 24 locally. Sixteen tests passed, including malformed parser input and FIFO regressions addressed following independent review. Both public animated SVG URLs returned HTTP 200 with content type `image/svg+xml`.

The historical cache benchmark in [validation.md](validation.md) predates parser hardening and is not a measurement of this published source revision. No final source performance claim is derived from that earlier run.

Local Chromium startup was blocked by socket permissions after the browser download. Remote UI validation remains pending; no interactive browser pass is claimed in this receipt. Claude and Codex host installation also require host specific validation.
